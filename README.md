# Smartway — календарь бухгалтера

Интерактивный календарь для штатных бухгалтеров малого и среднего бизнеса.

Календарь помогает просматривать ближайшие сроки подачи отчётности, уведомлений и платежей, переключаться между календарным и списочным представлениями, применять фильтры и искать события.

## Документация

- [Product Requirements Document](./PRD.md)

## Возможности демоверсии

- календарный и списочный режимы;
- данные за 2026 и 2027 годы из публичной Google-таблицы;
- фильтры по категории и типу события;
- текстовый поиск;
- карточка события с периодом, аудиторией и ссылкой на источник;
- адаптивная desktop/mobile-версия.

## Локальный запуск

```bash
npm install
npm run dev
```

Обновить данные из Google Sheets и собрать production-версию:

```bash
npm run build
```
