# Smartway — календарь бухгалтера

Продуктовая документация интерактивного календаря для штатных бухгалтеров малого и среднего бизнеса.

Календарь помогает просматривать ближайшие сроки подачи отчётности, уведомлений и платежей, переключаться между календарным и списочным представлениями, применять фильтры и искать события.
